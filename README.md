# 《符文战场》(Riftbound) 卡牌浏览与选购系统

基于 RiftAtlas (`zh-CN/cards`) 完整卡牌数据库构建的纯前端卡牌浏览、自由选卡加购、交互式预览看板与高清截图/多维文本表格导出工具。

## ✨ 核心功能

1. **完整中文卡牌数据库（1,530 张）**
   - 内置全量 11 个系列的 1,530 张《符文战场》中英双语卡牌数据（含官方中文译名、编号、法力费用、符能费用、战力、领域、类型、稀有度、系列、中文规则文本与背景故事）。
   - 支持 **6 大领域（炽烈/翠意/灵光/摧破/混沌/序理/无领域）多选**、**卡牌类型**、**稀有度**、**法力费用**、**所属系列**、**异画开关**、**指示物开关** 与 **高级语法搜索**（如 `t:单位 d:炽烈 c<=3 m>=4`）。
2. **全场景鼠标悬停高清卡牌预览**
   - 在主卡牌网格、列表视图、右侧购物车、预览看板弹窗及导出预览表格中，鼠标悬停在任意卡牌上即可实时弹出高清大图与完整规则说明。
3. **自由选卡与购物车数量管理**
   - 支持「左键点击卡图 +1 / 右键 -1」极速选卡模式，或通过卡牌底部的 `[-]` `[数量输入框]` `[+]` `[×3]` 自由调整数量。
   - 支持 **直接拖拽 `.csv` / `.txt` 文件到网页任意位置** 批量导入购物卡表（自动兼容 UTF-8 与 Excel GBK 编码）。
4. **交互式预览看板 & 2x 超清 PNG 预览截图导出**
   - 网格展示所有已选卡牌预览图与右上角醒目的数量角标 `×N`，支持按颜色/领域、类型、稀有度过滤与分组，一键导出 **2x 超清 PNG 预览长图** 或直接复制图片到剪贴板。
5. **可筛选/可自定义字段的纯文本表格导出**
   - 支持按颜色/领域、稀有度、卡牌类型、费用、系列对购物车卡牌进行筛选排序，并自由勾选导出字段列（卡牌名称、数量、颜色/领域、稀有度、卡牌类型、卡牌编号、法力费用、战力、所属系列）。
   - 支持导出为 **对齐纯文本表格**、**TSV (Excel/飞书直接粘贴)**、**Markdown 表格**、**极简购卡列表**，或下载为 `.csv (Excel)` 与 `.txt` 文件。

## 🚀 使用方式

- **本地双击即用**：直接双击打开 `index.html`、`启动卡牌购买系统.bat` 或 `符文战场_卡牌购买系统_单文件便携版.html` 即可运行（零环境依赖）。
