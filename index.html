🔍 RiftAtlas 卡牌搜索语法指南

直接输入任意中文/英文词即可同时匹配卡牌名称、卡牌编号、规则文本、关键词与英雄标签。此外还支持以下精确语法：

  • t:单位 或 t:unit / t:法术 / t:传奇 —— 按卡牌类型筛选
  • d:炽烈 或 d:fury / d:翠意 / d:灵光 —— 按领域筛选
  • c:2 / c<=3 / c>=5 —— 按法力费用比较筛选
  • m>=4 / m:3 —— 按战力 (Might) 比较筛选
  • r:稀有 或 r:epic / r:showcase —— 按稀有度筛选
  • s:ogn / s:arc / s:起源 —— 按系列代号或名称筛选
  • k:游走 / k:急速 —— 按关键词筛选
